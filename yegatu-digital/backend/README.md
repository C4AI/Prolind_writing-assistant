# Indigenous Backend

Este é um servidor backend construído com **Node.js**, **Express** e **TypeScript**, utilizando diversas bibliotecas modernas para autenticação, manipulação de cookies, requisições HTTP, testes automatizados e integração com Apache CouchDB.

---

## Requisitos

- Node.js 18+
- npm 9+
- Arquivo `.env` com suas variáveis de ambiente (veja exemplo abaixo)

```bash
CLOUDANT_API_KEY=${VALUE}
NODE_ENV=DEV
```

---

## Instalação

Clone o repositório e instale as dependências:

```bash
git clone https://github.ibm.com/BRL-indigenous/indigenous_backend
cd indigenous_backend
npm install
```

---

##  Execução

Execute o projeto na porta 3000:

```bash
npm run dev
```
